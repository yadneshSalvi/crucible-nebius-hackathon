# Local execution and trust boundaries

The React/Vite application on 127.0.0.1:4201 proxies `/api` to FastAPI on 127.0.0.1:4202. SQLite WAL transactions commit folio revisions, idempotency keys, job records and append-only events together. Browser mutations require a per-install local session token and an accepted same-origin request. This is a single-operator local workbench, not multi-tenant authorization or a deployed service.

The control plane executes only two authored adapter IDs. No paper upload, repository import, arbitrary URL fetch, model-produced code or arbitrary shell command is accepted. The data adapter fetches one fixed UCI URL and verifies its pinned archive/file digests. There is no generic import endpoint.

Each numerical attempt runs as a bounded subprocess with a credential-free environment, one BLAS thread, CPU/file/wall-time limits and a dedicated output directory. The predictor sees training targets and unlabeled evaluation features. A separate trusted verifier implementation joins sealed evaluation labels and recomputes metrics, preprocessing fingerprints, coverage, duplicate checks, scope, uncertainty and decision. Both processes share the local OS identity. This is code/process separation, not a hardened filesystem/network sandbox and not external scientific independence.

The planner receives an explicit whitelist of public source context, the fixed specification and released discovery aggregates. It cannot change methods, metric implementation, splits, label joins or the registered decision rule. A locally reviewed evidence change may add registered conditions to the discovery schedule, with the original locked contract retained. Confirmation registration is permanent before prediction. A workspace-wide holdout ledger binds the split, condition, numerical specification, implementation hashes, margin and alpha. A new folio cannot reset exposure. An exact repeat is labeled a reproducibility replay; a different plan is rejected until genuinely fresh held-out data or a predeclared family is available.

Jobs use generation fences. Cancellation first records `cancel_requested`, rejects stale commits, then terminates the local subprocess before reporting cancellation. External inference cancellation closes the request; remote termination, billing and unknown final usage are explicitly not guaranteed. On restart, ambiguous jobs become interrupted with the last durable checkpoint. A deliberate resume creates a new preserved attempt; no ambiguous metered request is silently retried. Events can be replayed by monotonically increasing cursor and the client polls as a fallback transport.

Artifacts are content addressed and hash-verified before download. Sealed labels and original source files containing them never enter the public artifact store before verification. ZIP export is unavailable before verification and is built from explicit allowlists, not a recursive repository archive. It releases frozen numerical code, licensed data, registered settings, predictions, verification, model/retrieval receipts and a readable HTML report for no-inference reproduction. Hashes establish tamper evidence, not truth of input assertions or third-party signatures.

Development reasoning uses the exact Fireworks NVIDIA Nemotron Ultra model at high reasoning, 32,000 output tokens and a 480-second timeout. The schema is in the prompt; no `response_format` is sent. Only final answer content is parsed, with strict local schema and lattice validation. Reasoning content is not retained. Receipts include exact provider/model, attempt status, request identity, token usage and estimated cost when supplied. No implicit fallback is implemented. The final Nebius adapter is explicit and disabled for this development phase; Ultra completion qualification remains pending.

Tavily performs bounded primary-source runtime retrieval. Accepted evidence changes add Light sensor tests to the actual finite discovery schedule. If no relevant source is returned, retrieval is context only. A source naming Light does not establish a new published correction; the original paper already considered feature combinations. Retrieved text is untrusted content, never execution instructions.
