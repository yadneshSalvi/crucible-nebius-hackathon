# Source-informed wheat measurement experiment

The wheat adapter is a new authored experiment on the pinned public GWHD corpus. It does not reproduce a WILDS result, its exact implementation, or its metric. Original source settings and current defaults differ, including ImageNet/COCO initialization ambiguity. An independent CV reviewer, practitioner acceptance requirement, collection independence, and new field-data custody are not established. Outputs remain descriptive finite-corpus measurements.

`science/wheat.py:SPEC` is hashed before preparation. Three authored seeds (11, 29, 47) each train TorchVision Faster R-CNN ResNet50-FPN for ten epochs, using an explicitly pinned ImageNet1K V1 backbone initialization. FrozenBatchNorm and three trainable backbone layers are explicit choices. Minimum input size is 800, maximum 1333; wheat/background heads replace the original classifier. The 1000-detection cap was selected before outcomes for the counting task and differs from a default/reference cap. Adam uses learning rate 0.0001, weight decay 0.0001, betas 0.9/0.999 and epsilon 1e-8. Native batch size is four; the final incomplete batch remains. The source inventory remains sorted. Each seed/epoch uses a full deterministic permutation from a separate CPU Python random.Random generator seeded seed*100000+epoch, collision-free across the three declared seeds and ten epochs. It does not alter global/model RNG state. Each epoch records its order seed and SHA256, and resumed training derives the same next order without inspecting outcomes. Epoch ten is selected for every seed, with no validation, tuning, early stopping, or checkpoint shopping.

Actual device, CPU/wall time, RSS, dependencies, epoch work and fallback enablement enter receipts. A random dummy tensor hardware test is engineering evidence, not a detector result. Each completed epoch replaces a resumable checkpoint and writes an immutable diagnostic/hash journal. Earlier full checkpoint bytes are not retained; all three final models are. Checkpoints load with `weights_only=True`. The full audited corpus roles determine training; there is no silent image or epoch cap.

Preparation audits exact source bytes, dimensions, decoded pixel hashes, box bounds, original session identities, and related group identities before fitting. It rejects duplicate identities/pixels and any session/group crossing roles. Source `final` becomes `confirmation`; continuous source xywh becomes xyxy without hidden clipping/exclusion. Original provenance and pre-fit source exclusions remain retained. Raw source manifests and evaluation boxes stay private. Final photographs stay private until all final predictions exist and the separate oracle verifies them. The predictor receives only images, checkpoints and a fixed task. Both processes share one OS identity: this is a code/process boundary, not a hostile-code sandbox, independent human review, or historical benchmark decontamination.

The finite recipes are native_full, native_noop, retain_768, retain_512, retain_256, native_tiles, degraded_tiles256, and native_multiscale. Every upload width, including 1024/no-op, uses the same lossless PNG encoding (compress_level6, optimizeFalse). Smaller inputs use Pillow LANCZOS downsampling, PNG encoding/decoding, then LANCZOS restoration to the original 1024 canvas. Native and no-op have identical encoded upload bytes and source-identical decoded pixels; original source-image provenance remains separately retained. Source filenames end `.png`, but the audited bytes include both JPEG and PNG; format/MIME is detected from bytes without conversion. Encoded payload bytes and actual processed pixel hashes are measured; actual network transfer is not claimed. This is **pixels retained before upload**, not physical altitude, camera, crop stage, biology, or physical blur.

Known SAHI inference uses its actual TorchVisionDetectionModel and get_sliced_prediction: 512-square slices, 0.2 overlap, no extra full-image pass, class-aware NMS at IoU0.5. SAHI is established prior work. The negative control tiles the already degraded 256-pixel upload. Native multiscale processes the full image at minimum sizes 640,680,720,760,800,840,880,920,960, followed by actual SAHI NMS. Its nine forward calls match the tile grid's call count. Tensor pixels, runtime, bytes, memory and cost can differ; no equal-cost superiority is claimed. Hooks record actual calls and padded tensor shapes.

The independent metric module never imports the detector or Torch. It reconstructs transformed pixels independently, audits original-coordinate lineage, tile offsets and NMS witnesses, and greedily matches descending-score predictions to unmatched targets at continuous IoU>=0.5. Retained detector scores are >0.5; coordinates use no inclusive `+1`. An unmatched prediction overlapping an already matched target at IoU>=0.5 is duplicate. Count MAE, signed bias, precision, recall, mean matched IoU and TP/(TP+FP+FN) remain visible. Empty/empty detection accuracy is one; undefined precision/recall stay null. These are authored application metrics, not WILDS accuracy or COCO mAP. Count agreement can conceal cancelling misses/false positives.

Seeds average within image, images within acquisition session, then sessions receive equal weight. Seeds, boxes, pixels and transformations do not inflate acquisition units. No CI or p-value is calculated while independence is unestablished. There is no default acceptable-error threshold or invented deployment recommendation.

Nullable metrics explicitly average defined seed values within each image before averaging defined images within session. Inference totals include all three training seeds; upload payload totals count each photograph once per recipe. UI box records contain only the predesignated discovery illustration (all three seeds) or the lexicographically first final identity, chosen before outcomes. Full per-image metrics, predictions and labels remain retained for every image.

Box artifacts use lossless float64 NPZ arrays with allow_pickle=False. Both raw shifted coordinates and actual SAHI-merged coordinates are preserved, with uint32 source witnesses. This matters because SAHI can shift NumPy float32 coordinates in float32 while an equivalent Python-float shift retains more bits. Storage adds no rounding and keeps the existing 1e-4 coordinate/1e-6 score lineage witness tolerance. The combined seed manifest references per-seed arrays instead of duplicating them in canonical JSON.

Source photographs use verified hardlinks on one filesystem; cross-filesystem copying is budgeted before materialization. Every-stage hashes detect mutation of the linked source; this is not independent immutable storage. The ingestion gate budgets metadata plus any cross-filesystem image copies and a 2GiB reserve. The separate full-run gate includes three latest Adam states (3×576MiB), three final models (3×192MiB), a 576MiB atomic checkpoint temporary, initialization, 768MiB ancillary outputs, all bounded predictions and one complete streamed portable ZIP. With discovery image count D, final count F, cap C=1000 and three seeds, the conservative uncompressed numeric prediction bound is 92×C×3×(32D+28F) bytes. Raw outputs use 48 bytes and each possible selected output uses 40 bytes plus a 4-byte witness. No favorable predicted count or compression ratio is assumed. Only hash-bound canonical model slots receive capped allocated-byte credits; source aliases, arbitrary files and failed outputs cannot reduce future prediction, temporary or ZIP reserves. Export checks actual canonical bytes plus 5%/16MiB overhead and reserve before writing; source-image files and NPZs are stored without unnecessary recompression. Insufficient storage is an operational failure before work, never a scientific refutation or permission to reduce the corpus.

Registration binds one selected policy plus native_full/native_tiles/native_multiscale controls, deduplicated in that order. It also binds the exact retained discovery parent, all model hashes, corpus/split, source/code/specification and analysis. Independently verified native/no-op prediction equivalence across discovery envelopes is mandatory. All final predictions complete before labels join; policy/family/lineage changes cannot reuse the final corpus, and discovery stops after registration. The API separately owns cross-folio image/pixel exposure accounting.

`python -m science.wheat_cli metadata --output metadata.json` is pure metadata and imports no Torch. Other stages take `--input request.json --output result.json`: prepare, train, explore, predict, verify, export, rerun, reverify. Preparation needs root/source_manifest; training needs the locked returned contract and initialization {name,path,sha256,source_url,license}; exploration needs recipe_ids. Final registration needs policy_id, registered_at, reviewer_name and parent_discovery_sha256. The control plane authorizes source-enabled recipes.

Preparation freezes the exact repository requirements-wheat.txt, full transitive hash-locked requirements-wheat.lock and supplemental requirements-wheat-linux-cuda.lock under case/environment/, records their provenance and hashes, and binds the base lock digest into the contract. All three exact files are exported at the bundle root and retained in case/environment/. Locks are installation recipes, not independent installed-environment attestations. Install the base environment with Python3.13 and `python3.13 -m pip install --require-hashes -r requirements-wheat.lock` (or a prepared wheelhouse). The optional Linux CUDA recipe preserves the fixed package versions; its installation and GPU execution remain unqualified. Actual training receipts are case/model/seed-11/training-receipt.json, case/model/seed-29/training-receipt.json and case/model/seed-47/training-receipt.json.

Exports retain audited source/model bytes with attribution and unresolved rights statements, released boxes, frozen code, dependencies, predictions, receipts and metrics. `python reproduce.py --verify-only` checks logical hashes without writing aliases; missing historical aliases are checked against canonical retained bytes. `--metrics-only` independently recomputes metrics without importing Torch; the default performs fresh fixed-checkpoint inference then recomputes metrics. Replay requires exact identities/counts, coordinate tolerance0.001 and score tolerance0.00001. It claims neither retraining nor fresh confirmation. After dependency installation, replay requires no network or provider key.

The approximately31GiB full-run scope covers one retained ZIP, not extraction or fresh replay. The exported manifest workspace separately reports canonical_extraction_bytes_upper_bound and fresh_inference.additional_bytes (or metrics_only.additional_bytes), plus reserve. Before extraction, allow these bytes beyond the ZIP and installed dependencies. Admission reads actual canonical image/model sizes, retained scalar/NPZ sizes/counts and schedules, and keeps the full fixed detector-cap output bound. Full-copy fallback is reserved for every missing required final alias and new replay capsule even if hardlinks use less. Only final aliases needed by the oracle are materialized; unrelated historical training aliases remain logical references.

The portable runner and direct fresh-inference rerun check workspace before creating aliases, requests or attempts. Insufficient storage fails before those writes; NPZ publication retains its per-write reserve guard. Recipients must check archive extraction space against the exported manifest before using their archive utility. This workspace is separate from training/export admission and includes neither a new training fit nor another ZIP.
