# Case selection registry

Selection occurred before fitting the authored comparisons. No case was selected because it produced a reversal. This is a two-adapter local implementation, not the plans' unbuilt six-slot registry, 108-case frozen evaluation, or a successful literature-reproduction benchmark.

| Candidate | Decision | Reason and accepted scope |
| --- | --- | --- |
| UCI Occupancy Detection, ID 357 | Accepted as an authored public-data comparison | Official accessible CC BY 4.0 files, small numeric binary task, exact predefined split files, useful timestamp audit. New trusted Python random-forest/logistic comparison. Original R code has no established reuse license, so none is copied. No paper protocol reproduction, novelty claim, independent-day inference or cross-building generalization. |
| authored-xor-groups-v1 | Accepted, explicitly controlled synthetic | Known nonlinear generator, independent group streams and disjoint splits permit testing the full statistical/verifier flow. No empirical claim about published research. Generator choices were fixed before fitting. |
| Original Occupancy paper claim and linked R scripts | Not accepted as a paper reproduction | A separately reviewed numerical claim, exact original protocol matching, code licensing and independent scientific sign-off are incomplete. Data permission does not grant permission to redistribute scripts or the paper. |
| UCI Bank Marketing, ID 222 | Deferred; no fit performed | Valuable mixed-data candidate, but variant, timestamp/entity structure and prediction-time availability (including call-duration leakage) require a separate reviewed contract and categorical adapter. No outcomes inspected. |
| UCI MAGIC Gamma Telescope, ID 159 | Deferred; no fit performed | Domain-appropriate operating-point/ROC analysis and an exact paper/protocol claim are not implemented; balanced accuracy alone is not a substitute. No outcomes inspected. |
| Arbitrary uploaded repositories or Python | Unsupported in this local release | The local same-OS process boundary is designed for trusted authored adapters and is not qualified for untrusted execution. |
| Remaining mixed/categorical and grouped task slots in ignored plans | Unfilled | No frozen multi-paper registry, external reviewers, comparator benchmark or participant study is represented as completed. |

Primary dataset entries: [Occupancy Detection](https://archive.ics.uci.edu/dataset/357/occupancy-detection), [Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank-marketing), [MAGIC Gamma Telescope](https://archive.ics.uci.edu/dataset/159/magic+gamma+telescope). Deferred entries are methodological audit candidates, not measured Crucible results.

Local operator review is a real approval of this authored contract. It is labeled accurately and does not replace the pending external methodologist gate for broader scientific claims. Sound, adverse and inconclusive outcomes receive the same retention policy. Model/retrieval proposals and rejected or failed attempts remain in the folio's separate audit ledger.
